# Environment Variables Setup

## Quick Setup

1. Copy the example environment file:

   ```bash
   cp env.example .env
   ```

2. Update the `.env` file with your actual values:

## Required Environment Variables

### Database

- `DB_URL`: MongoDB connection string
  - Local: `mongodb://localhost:27017/ecommerce`
  - Cloud: `mongodb+srv://username:password@cluster.mongodb.net/ecommerce`

### JWT Authentication

- `JWT_SECRET`: A long, random string for signing JWT tokens
- `JWT_EXPIRE`: Token expiration time (e.g., "7d", "24h")
- `COOKIE_EXPIRE`: Cookie expiration in days

### Cloudinary (Image Upload)

1. Sign up at [cloudinary.com](https://cloudinary.com)
2. Get your credentials from the dashboard
3. Update:
   - `CLOUDINARY_NAME`
   - `CLOUDINARY_API_KEY`
   - `CLOUDINARY_API_SECRET`

### Razorpay (Payment Gateway)

1. Sign up at [razorpay.com](https://razorpay.com)
2. Get your API keys from the dashboard
3. Update:
   - `RAZORPAY_KEY_ID`
   - `RAZORPAY_KEY_SECRET`

### Email (SMTP)

For Gmail:

1. Enable 2-factor authentication
2. Generate an App Password
3. Update:
   - `SMTP_EMAIL`: Your Gmail address
   - `SMTP_PASSWORD`: Your App Password (not regular password)

### Optional

- `FRONTEND_URL`: Your frontend URL for CORS
- `STRIPE_SECRET_KEY`: If using Stripe payments
- `STRIPE_PUBLISHABLE_KEY`: If using Stripe payments

## Security Notes

- Never commit `.env` files to version control
- Use strong, unique values for `JWT_SECRET`
- Keep your API keys secure
- Use different credentials for development and production
